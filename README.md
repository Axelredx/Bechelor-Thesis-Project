# Abstarct

In recent years, the evolution of Large Language Models (LLMs) has opened new perspectives for business process automation and intelligent information management. This thesis presents the development and implementation of an intelligent document management system based on the Model Context Protocol (MCP), an interface protocol that enables structured interaction between AI systems and external resources. The project’s goal—originating from work carried out during a university internship—is to automate the processes of storing, analyzing, and retrieving large volumes of heterogeneous documents, leveraging AI models’ capabilities to extract, summarize, and present information in natural language. Through the MCP server, the application allows users to upload documents—such as invoices, financial statements, or transport documents—and subsequently query the system (via an AI chat interface) for specific information about the stored data.
